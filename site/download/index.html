Looking for official Mac installers…

Installing on macOS

Open the disk image and drag Forge to Applications. These preview builds are not yet signed and notarized, so Gatekeeper may block the first launch. Open only if you trust the project, then review macOS Privacy & Security to allow it. You must confirm installation and launch yourself.

Installing on Windows

Open the downloaded setup file and follow the prompts. Because these preview builds are not yet code-signed, Windows may show a SmartScreen notice. Review the publisher details; you still need to approve the installer.
