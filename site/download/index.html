Common questions

Need a hand?

Which platform should I download for? +

Forge provides native builds. Use the macOS DMG for Mac computers, the Windows Installer (EXE) for Windows 10/11, and the Android APK for phones and tablets.

Is Forge safe to install? +

Yes. Forge is 100% open-source and local-first. It requires no user accounts and includes no third-party tracking scripts. Being community-developed and unsigned, macOS Gatekeeper or Windows SmartScreen may warn about "untrusted" or "unknown" publishers; this is normal for independent software.

How do I update Forge? +

Forge includes an in-app update checker that detects new GitHub releases. You can also manually download the latest version from this portal. Your library, playlists, and listening history are stored locally and are preserved during updates.
